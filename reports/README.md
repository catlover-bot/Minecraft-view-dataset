# Reports Directory Guide

このディレクトリは、用途ごとに次のように分かれています。

- `final/`: 最終採用結果（最初に見る場所）
- `support/`: 補助レポート（比較・評価ガイド・中間まとめ）
- `figures/`: 図と図の元データ
- `statistics/`: seed反復・有意差検定など
- `failure_analysis/`: 失敗ケース分析
- 直下の `*.md` / `*.json`: 互換用の移動案内ファイル

最短で確認するファイル:

1. `final/summary_ja.md`
2. `final/report_full_ja.md`
3. `final/decision_diversification_ja.md`
4. `final/artifacts_index.md`
