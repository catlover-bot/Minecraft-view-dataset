Selected completed outcomes number 959. Buildings, rather than descriptions or Builder calls, are the independent units. All aggregate means first average within a building, then weight buildings equally; valid counts are shown with each condition. The strict translation evaluator is server_v2.2_strict_translation.

## Separate exploratory CPU attribute proxy

A separate, new CPU-derived attribute fidelity proxy was specified before these scores and associations were calculated. It uses strict material F1, coarse material F1, missing-safe dimension accuracy and typed field completeness, with fixed weights 0.30/0.25/0.25/0.20. All 180 descriptions have exact original-source, input and GT hash binding. Missing or invalid dimensions are penalized rather than filled from GT. This proxy is not conventional description quality or a human judgment. All 360 specified associations are retained, including nonestimable strata and unstable intervals; no p-value or Holm family was added. Two Builder outcomes repeat each description. Intervals resample 60 building clusters 2,000 times with PCG64 seed 20261016; this seed is not a decoding seed.

For valid O reconstructions, the composite proxy has pooled Spearman associations of 0.3932 (95% CI [0.2514, 0.5217]; 177 descriptions, 60 buildings) with OpenAI Builder IoU and 0.3745 (95% CI [0.2278, 0.5126]; 179 descriptions, 60 buildings) with Anthropic Builder IoU. Using the mean of both Builders only when both are valid gives 0.4183 (95% CI [0.2662, 0.5488]; 176 descriptions, 60 buildings). Within-building centered associations are OpenAI 0.4033 (95% CI [0.2204, 0.6077]; 177 descriptions, 60 buildings), Anthropic 0.4042 (95% CI [0.2409, 0.5761]; 179 descriptions, 60 buildings), and both-Builder mean 0.4478 (95% CI [0.2607, 0.6358]; 176 descriptions, 60 buildings). These exploratory associations do not validate conventional description quality or establish causality. All five components, rank-centered results, provider strata and failure0 sensitivity records remain in the separate exploratory appendix, including null and unstable intervals. Across the full fixed analysis grid, 144 records have point estimates and cluster intervals, 24 retain estimates without an eligible cluster interval, 12 are undefined because of constant variables, and 180 provider-stratified within-building records are not estimable with one description per building.
