# Exploratory CPU-derived attribute fidelity proxy: frozen specification

Specification ID: `goal008_missing_safe_attribute_fidelity_v1`.
This specification is recorded before any Goal008 proxy scores or correlations are computed. Weights, normalizations, eligibility rules and analyses will not be selected by observed association strength. This is a **new exploratory CPU-derived attribute fidelity proxy**, not conventional description quality, human judgment, a recovered historical score, or the Goal007 confirmatory analysis.

## Sources and scope

Use exactly the 180 frozen O JSON descriptions (60 v4 buildings × OpenAI/Anthropic/Gemini description providers) audited against the original fixed manifest. Each description is distinct from its two Builder observations. Record scene/provider/model, original source path/bytes/SHA256, O input ID/SHA256, J correspondence, GT bbox/voxel/grid SHA256, specification SHA256 and scorer code SHA256. Require all180 identities and hashes to match before full-cohort analysis; any binding failure stops computation without fabrication. Read GT through the existing pickle-forbidding `server_v2.data.load_scene` reader. No response regeneration, LLM scoring, API/key inquiry or human experiment.

## Components, all on [0,1]

1. **Strict material-set F1**: compare explicitly named occupied material identifiers against the GT material target set. Accept strings or dictionaries with a string `name`; strip surrounding whitespace, lowercase, and remove only the `minecraft:` prefix. Require identifier syntax `[a-z0-9_]+`; reject explicit alternatives (`_or_`, `or`, `unknown`, `unspecified`) and invalid punctuation/whitespace. Empty, wrong-type and ambiguous names contribute distinct deterministic unmatched sentinel tokens instead of being silently dropped or matched to OTHER. Identical invalid values deduplicate as sets do. Exact air/cave_air/void_air are excluded. A missing/wrong-type materials list yields empty prediction and F1=0. Valid nonidentical IDs remain different: no stonebrick/stone_bricks or slab synonym merging in this strict component.
2. **Coarse material-set F1**: apply the fixed `tools.evaluate_rebuild_metrics.coarse_material` mapping to accepted IDs after its existing `normalize_block_type` normalization. These legacy coarse categories merge material classes only for this exploratory component, never Goal007 metrics. Invalid-name sentinel tokens remain unmatched. A legacy OTHER category retains the exact normalized token (`OTHER:<token>`), preventing arbitrary unknown identifiers from earning generic OTHER matches. Both strict and coarse F1 are `2*intersection/(pred_count+GT_count)`; empty target GT is an error.
3. **Dimension relative accuracy**: use inclusive storage bbox width=xmax−xmin+1, depth=zmax−zmin+1, height=ymax−ymin+1, matching the legacy reference frame; also record occupied extents to expose any padded-air difference. Accept finite positive JSON numbers (including exact JSON Decimal), not bool/string, at most1,000,000. Round to nearest integer using Python ties-to-even, minimum1. An absent/invalid axis remains null and contributes relative error1; it is never replaced by GT. Other axes use `abs(pred−GT)/GT`. Score=`max(0,1−min(1,mean_of_three_relative_errors))`. All3 missing gives0. Oversized relative error may legitimately drive the aggregate to0. Store each axis's predicted value, reason, absolute error/null and relative error.
4. **Typed field completeness**: equal mean of5 binary fields: summary is a string with at least30 stripped characters; at least2 distinct accepted nonair material identifiers; all3 dimensions valid under the rule above; at least2 nonempty string elements; at least2 nonempty string rebuild_hints. Wrong types do not count as present. This measures schema content, not semantic correctness; ties/constants are expected and must be reported.
5. **Fixed composite**: `0.30*strict_material_f1 + 0.25*coarse_material_f1 + 0.25*dimension_accuracy + 0.20*completeness`. Weights follow the historical script without fitting. Every subscore is separately retained; no missing-source reconstruction is allowed. A structurally valid source record with missing fields receives the specified penalties, not a fabricated field value.

GT material target: count exact nonair IDs across the complete verified occupied voxel grid; sort by descending count then identifier lexicographically. Keep at most6 with frequency≥0.03. If none meets threshold, keep the top6. This target emphasizes dominant GT materials; rare materials can be omitted. Log selected IDs/counts/fractions. The lexical tie break is fixed and may differ from historical Counter encounter order. GT bbox empty/nonpositive or GT occupied set empty is a hard error.

## Relationship to the legacy script

`tools/evaluate_description_quality.py` supplies the four-component structure, dominant-material top6/3% convention and weights. Its missing/invalid-dimension GT fallback, permissive string coercions, pickle-enabled loading, material aliases in its so-called strict score, and generic OTHER matches are not carried into this missing-safe definition. No faithful-legacy-score is calculated: exact historical comparability is not claimed. The current proxy's strict material F1 uses exact identifiers; coarse F1 is explicitly a separate relaxation. Hash both reference scripts and the new scorer. The scorer evaluates only the top-level structured attributes, not every statement in summary or hints.

## Analyses fixed before results

See [stats_definition.md](stats_definition.md): seed20261016,2,000 building-cluster bootstrap draws; all5 components, both Builders and both-valid Builder mean; pooled Spearman, within-building centered and rank-centered associations; overall and all3 description-provider strata; valid-only and separate bounded-IoU failure0 sensitivity. All planned records, nonestimable/constant/tied/missing cases and denominators are retained. No new p-value or Holm family is created. Within a single description-provider stratum there is only1 description per building, so within-building associations are explicitly nonestimable.

The old RQ2 remains `NOT_TESTABLE_WITH_CURRENT_MATCHED_SCORES`. This analysis asks a different, exploratory question. Shared GT between proxy components and reconstruction metrics, fixed prompts/models, dependent descriptions/Builders, multiple exploratory analyses, measurement choices and source selection prevent claims of independent human-quality validity or causality. A composite association cannot establish that conventional caption quality predicts (or fails to predict) reconstruction.
