# 幾何ベースラインと新指標の所見（Goal010 v2）

分類：`POST_HOC_EXPLORATORY / CPU_DIAGNOSTIC`。本稿は Stage4 の保存済み集計値の読取り・照合だけで作成した。新しい指標計算、ブートストラップ、モデル照会は行っていない。旧 Goal010 の結論を有利な指標に置き換えるものではない。

**結論：Builder と固定形状の優劣は、何を測るかで変わる。** O の filled-box 対照は aligned occupancy IoU と recall で両 Builder を上回るが、Builder は occupancy precision と surface F1@1/@2 で上回る。P でも filled-box より Builder の IoU は高い一方、recall と footprint IoU は低い。したがって「LLM は単純形状より一律に良い／悪い」とは結論できない。

## 集計規約と母数

O は保存された画像説明 JSON の寸法から作った対照、P はGTから与えられた特権的な寸法・bbox情報による対照であり、両者を画像だけを入力する同一難度の課題とは扱わない。固定 filled_box / six_face_shell の480予測を再利用し、場面ごとの最適化は加えていない。baseline の人工材質は材質比較から除いた。

全表の差は **Builder − baseline**。下記コア6指標は大きいほど良い。各 building 内の適格な説明生成元ペアを平均した後、building を等重みで平均した。all-provider の O は最大180ペアでも独立単位は60建築であり、2 Builder を独立な120建築としていない。P は60ペア。aligned は既存の occupancy 最適平行移動を各予測に適用し、各新指標のための再最適化はない。GTを用いた位置合わせ後の値であり、世界原点の推定能力を示す値ではない。absolute の全比較は機械可読表に併記されている。

CV = common_valid。F0 = known_failure0：既知の完了した出力失敗のみを、事前固定した bounded 指標で0補完する補助方針。正常出力で定義不能な値、HTTP520、resource limit を0にはしない。条件付き材質正解率・無限定の誤差・volume ratio はF0対象外。Oの補完はOpenAI3件・Anthropic1件、Pは両Builder0件。

CI は planned 60 building をフレームに残す cluster bootstrap（NumPy PCG64、seed 20261017、2000反復、percentile/type7）の95%区間である。新たなp値・Holm family・confirmatory判定はない。多数の指標・比較の区間は多重性調整されていないため、「有意」「一般的な優越」とは呼ばない。

## 指標を分けると何が変わるか

O-filledでは、CVのIoU差はOpenAI −0.011960 [−0.020352, −0.003229]、Anthropic −0.011615 [−0.019086, −0.004501]。Recall差はそれぞれ−0.211233と−0.153559で、filled対照がGT占有を広く覆う。一方Precision差は+0.092574/+0.065285、Surface F1@1差は+0.099288/+0.064520、@2差は+0.091993/+0.055132で、これらのCIは両Builderとも0を含まない。IoU・Precision・Recallの分離が、過剰占有を許してGTを覆うfilled対照とBuilderの差を示す。ただしsurfaceは内壁を含み得る6近傍boundary voxel間の距離であり、見える外観・人の好み・画像への忠実度を直接測っていない。

O-filledのFootprint差はCVでは+0.005806/+0.000194、F0では−0.002448/−0.000758に反転するが、4区間とも0を含む。したがって「F0でも全コア指標の方向は不変」「FootprintでBuilderが優れる」とは書けない。IoU・Precision・Recall・Surface F1@1/@2については、両BuilderのCVとF0で点推定の符号が維持される。

O-shellでは両BuilderのIoU・Recall・Footprint・Surface F1の点推定が正で、対応するCV区間は0を含まない。PrecisionのCV区間は両Builderとも0を含む。AnthropicのPrecisionは点推定が負であり、IoUだけで全体を代表させられない。

P-filledでは、CVのIoU差はOpenAI +0.018983 [0.005379, 0.032997]、Anthropic +0.020717 [0.013983, 0.027726]。一方、Recall差は−0.701731/−0.132627、Footprint差は−0.092274/−0.027945で、これら4区間は0を含まない。P-filledのRecall=1はGT bboxを丸ごと埋める構築規則に由来するため、その優位だけでよい再建築と見なさない。P-shellでは両BuilderのIoUは正だが、AnthropicのPrecisionは−0.001650 [−0.013292, 0.010920]、Surface F1@1差は+0.015545 [−0.007916, 0.039553]と0を含む。

既存の順位診断1560行の内訳は、反転247、非反転591、順位なし／同点722。各行は同じ適格ペア集合へ交差させてから、IoUと別指標の平均差の向きだけを比較する記述診断であり、1560独立試験ではない。aligned/all-providerの主要5指標（IoU以外）×8群では40行中14反転、26非反転。14件にはCIが0を含むFootprintやPrecisionも含まれるため、反転件数を確定的な勝敗数とは解釈しない。[全順位診断](analysis/4_summary/metric_rank_reversals.csv) を省略せず保持している。
