# Goal010 Phase1 単純幾何baselineの解釈

POST_HOC_EXPLORATORY / CPU_DIAGNOSTIC。主要なaligned occupancy IoUでは、Oの寸法推定だけから作る充填boxが両Builderの平均を上回った。Builder−boxの対応差はOpenAI −0.0119601（95% bootstrap CI [−0.0203523, −0.0032289]）、Anthropic −0.0116147（[−0.0190860, −0.0045007]）である。この固定データと評価法において、OのLLM再構築が寸法のみの充填boxより主占有指標で優れるという主張は支持されない。6面shellとの比較で差が正であることだけを選んで、充填boxの結果を省略しない。

この診断は占有形状の限定された比較である。材質、意味内容、部品の対応、操作の実用性などをまとめて評価しておらず、LLMの能力一般が無用だという結論にはならない。baselineは全voxelを定数stoneで表し、材質指標を計算・比較していない。

O対照は保存記述JSONのwidth/height/depthだけを使用する弱い構造対照で、GTを参照せず、固定丸め規則と原点から充填boxまたは6面shellを構成した。P対照は入力に開示されたGT world bboxを使うため、寸法・配置情報を持つ強い対照である。PとOの対照平均の直接比較を入力情報が等しい実験と解釈しない。240入力（O 180、P 60）から2形状、計480予測をGT評価より前に保存した。両Builderへ同一予測を対応付け、Builderごとのbaseline再生成やGTを使う形状調整は行っていない。

主比較は共通valid入力に限定し、建築内のeligible記述入力を平均してから60建築を等重みで平均する。OではOpenAI177/180、Anthropic179/180 pair、Pでは各60/60 pairが対応した。各rowのBuilder平均と対照平均は同じ入力集合に基づくため、Oの対照平均がBuilder間で僅かに異なるのは除外入力の違いによる。177/179入力を独立建築へ数え直さず、240入力、480予測、3840展開pair、80比較を標本数とも呼ばない。区間は固定した建築単位の2000回bootstrapによる保存値で、以下の全行が2000/2000回有効だった。p値や有意性の判定は追加していない。

aligned評価はGTに対する占有最適の平行移動を許し、原点の異なる予測の配置差を取り除く。baselineにもBuilderにも同じ厳密評価を適用するが、特に原点固定のO対照を実際に正しいworld位置へ置ける能力とは区別する。予測を生成する段階でGTを使わなくても、評価時に得る最適配置の利点はある。rotation・scale・切り取りは許していない。

absoluteは保存world座標のままの補足評価であり、形状だけでなく原点・配置の取り扱いを強く含む。例えばP/OpenAIの充填box差はabsolute −0.0676333からaligned +0.0189827へ変わる。これだけから形状生成の改善や劣化を因果的に説明しない。absoluteの主要8行も省略せず示す。

building034のP充填boxは入力bboxをそのまま埋めたもので、56×20×36=40320 voxel、GT occupied数4912、IoUは4912/40320=0.1218254となる。absoluteとalignedは同じ値である。当該建築ではP bbox、storage bbox、occupied bboxが一致し、保存されたP−storage体積差は0だった。この例の一致を、一般にstorage paddingとoccupied bboxを区別しなくてよい理由にはしない。P充填boxの密度恒等式は60建築すべてで検査済みである。
